# Моя обычная жизнь — прототип

Симулятор жизни для Telegram (Mini App).  
Сейчас: **универсальный движок + полный этап 0–3 года + 3 слота сохранений**.

## Как тестировать прямо сейчас

### Вариант 1 — браузер (самый быстрый)
1. Распакуй архив.
2. Открой файл `index.html` в Chrome / Safari на телефоне или компьютере.
3. Нажми **«Новая жизнь»** и играй.

Сохранения пишутся в `localStorage` браузера (3 слота).

### Вариант 2 — Telegram Mini App
1. Залей папку на любой статический хостинг (GitHub Pages, Cloudflare Pages, Netlify).
2. В @BotFather → твой бот → **Bot Settings** → **Menu Button** / **Configure Mini App** → укажи URL.
3. Или отправь пользователю кнопку `web_app` с этим URL.

## Что уже работает
- **Все этапы жизни** от рождения до финала
- Статы, path/tags, flags, relationships
- 3 слота + **4-й слот за Stars**
- **Магазин Stars:** темы, открытка биографии, премиум-ветки, отмены, доп. попытка викторины
- **Достижения**
- **Мини-игра** (школьная викторина) + платная повторная попытка
- **Премиум-ветки:** заграница, творчество, второй шанс после 40
- Финал: открытка + «Поделиться»
- В браузере покупки в **тест-режиме** (confirm). Для боя нужен invoice-link с бэкенда
